Observations from the source audit (before any change)
------------------------------------------------------
- TT: 65,536 entries x 32 B = 2 MiB, calloc/free per Hard search.
  Blind overwrite replacement; bounds stored from the tightened window.
- Zobrist hash recomputed from scratch (64 cell reads) at every interior node.
- Move generation and application are scalar (rules.c); GameState is copied
  by value (~264 B) at every node.
- Medium never allocates a TT; Hard only.
- Leaf nodes generate all legal moves before the depth<=0 evaluation test.
- Evaluation computes every component for every difficulty (2 legal-move
  enumerations + 4 full-board passes per leaf).
- Clock: timespec_get(TIME_UTC) (wall clock), checked every 1024 nodes.
- Endgame: Hard extends max_depth to the number of empty squares when
  empty <= 12; no separate exact solver.
