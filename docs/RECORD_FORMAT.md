# Reversi 棋谱格式 v1

日期：2026-10-24  
版本：1  
实现：`src/analysis/record.c`

该格式是 Reversi Lab 的公开棋谱交换格式。它是本项目自定义的格式，
**不是**任何其他翻转棋工具的标准，也不声称兼容其他格式。

## 1. 编码与结构

- 编码：ASCII；换行 `LF`（读取时接受 `CRLF`）。
- 以行为单位；空行与以 `#` 开头的行被忽略。
- 第一行必须是 `reversi-record 1`。
- 每行由空白分隔的 token 组成；token 内不允许空白。
- 坐标：`a1`–`h8`。`a1` 是左下角，`h8` 是右上角；大小写不敏感。
- 棋谱总长度上限 **8192 字节**（含换行）。

## 2. 行类型

### 2.1 头部（必需，一次）

```text
reversi-record 1
```

版本号不是 `1` 时拒绝。

### 2.2 结果（可选，一次）

```text
result B+4
result W+2
result D
result -
```

- `B+n` / `W+n`：黑/白胜，`n` 为终局子差（正整数）。
- `D`：平局。
- `-`：未结束。
- 若给出结果，导入时会用重放后的终局校验；不一致则拒绝。

### 2.3 主线（可选，一次）

```text
moves d3 c3 f4 pass e6
```

- 从标准开局开始，按顺序重放。
- `pass` 表示当前行动方无合法着法、显式让过。
- 一次着法导致对手无合法着法时，规则引擎会自动跳过；不需要写 `pass`。
- 主线最多 64 个 ply。

### 2.4 分支（可选，最多 8 行）

```text
variation <ply> <token> ...
```

- `<ply>` 是主线上的 0-based 位置；`0` 表示开局前。
- 分支从该位置开始重放；第一个 token 通常是主线该步之外的另一种选择。
- 分支行之间可以任意顺序；导入时先重放主线，再逐个建立分支。
- 只导出**一层**分支：分支内部再分出的兄弟分支不会写入 v1。
- 每条分支最多 64 个 token。

## 3. 示例

```text
# A short reviewed game
reversi-record 1
result -
moves d3 c3 f4 e6
variation 0 c4 e3
variation 2 f5
```

含义：主线 `d3 c3 f4 e6`；在开局前另走 `c4 e3`；在主线第 2 步之后
另走 `f5`。

## 4. 导入规则

- 每个 token 都经 `move_from_notation()` 与规则引擎验证；非法着法、
  在已结束局面继续走子、在无合法着法时未写 `pass`，都会失败。
- 导入在临时会话中进行；失败时会话保持不变并返回错误文本。
- 重复的 `moves`、`result` 行、未知键、错误版本、非法 ply 均拒绝。
- 结果行与实际终局不一致时拒绝，不做“尽力修复”。

## 5. 导出规则

- 主线从根沿首子链导出。
- 结果由主线终点局面生成：`B+n`、`W+n`、`D` 或 `-`。
- 每个主线节点的非首子分支各写一行 `variation`，沿该分支的首子链导出。
- 超过 8 条分支或 8192 字节时导出失败（返回 0），由 UI 提示，
  不会静默截断。

## 6. 兼容性声明

该格式只保证与 Reversi Lab v1 的写入/读取一致。未实现、也不声称支持
其他翻转棋软件的棋谱格式。
